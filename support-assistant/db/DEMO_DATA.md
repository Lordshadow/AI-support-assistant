# Demo database data

After starting PostgreSQL and applying migrations, run the seed from the
`support-assistant` directory:

```powershell
python -m scripts.seed_demo_db
```

The command replaces only rows generated by this seed (`demo_*` IDs), so it is
safe to rerun. It creates:

- 2,000 computer-part products with descriptions, four structured
  specifications, FAQs, aliases, prices, discounts, and stock status.
- 1,000 customers with deterministic dummy contact identifiers and language
  preferences.
- 2,500 orders across processing, shipped, delivered, and cancelled states.
- 1,000 refund requests covering amounts from INR 100 through INR 50,000,
  including the INR 2,000 auto-refund boundary and approval states.

The generator intentionally replaces only its own `demo_*` rows on every run,
which keeps local testing repeatable without touching real-looking rows.
